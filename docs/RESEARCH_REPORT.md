# Исследовательский отчёт — FOREST BEAVER

Команда **Super_Бобры**, КосмоХакатон 2026, «Спутниковая верификация зелёных инвестиций и углеродных кредитов».

Все числа ниже получены сервисом на данных из `data/` (файлы совпадают с
`data/file_catalog.csv` по SHA-256). Воспроизведение:
`./run.sh` или `PYTHONPATH=src python3 -m canopy.cli run --aoi <AOI> --from 2019 --to 2024`.
Готовые отчёты сервиса: [`examples/`](../examples/).

## 1. Подход и собственный вклад

Основной расчёт — разность запасов (stock-difference) по правилам постановки:
углерод в живой надземной биомассе, `c = AGB · 0,47`, площадное взвешивание по
пересечению пикселя с контуром, `E = −ΔC · 44/12`, потенциальные единицы по
общей базовой линии из `data/methodology`. Биомасса берётся из ESA CCI v7.0,
очаги изменений выделяются по разности карт CCI с порогом по собственной
ошибке продукта, а Sentinel-2, GFC и MODIS используются как подтверждения и для
датировки. Причина нарушения указывается только при подтверждении, иначе
статус «причина не установлена». Сервис принимает произвольный контур до 20 км²
и период 2019–2024 без правки кода. Если данных недостаточно, расчёт единиц
недоступен, а не заменяется значением.

## 2. Эксперимент 1: как обрабатывать нули в CCI (сравнение вариантов на одних данных)

В CCI Biomass нет тега NoData, ноль допустим. Сравнили два варианта:
(А) пиксель с AGB = 0 и SD = 0 считается пропуском; (Б) ноль — обычное значение.
Критерий: воспроизведение средних запасов, опубликованных организаторами в
`baseline.csv`.

| Участок, год | Опубликовано, т C/га | Вариант А | Вариант Б |
|---|---|---|---|
| RU_TVER_01, 2015 | 83,752 | 83,797 (+0,05 %) | 83,752 |
| RU_MORDOVIA_03, 2015 | 46,343 | 50,266 (+8,5 %) | 46,343 |
| RU_MORDOVIA_03, 2019 | 36,418 | 39,671 (+8,9 %) | 36,418 |
| RU_MORDOVIA_04, 2015 | 12,998 | 15,834 (+21,8 %) | 12,998 |
| RU_MORDOVIA_04, 2019 | 13,176 | 15,747 (+19,5 %) | 13,176 |

Вариант Б совпадает с опубликованными значениями на всех 8 контрольных
значениях (расхождение порядка 1e-11). Вариант А уверенно завышает запас там,
где покрова нет, а в данных все 562 пикселя с AGB = 0 (участок Мордовия-04)
имеют SD = 0. То есть это безлесные пиксели, а не пропуски. Вариант А также нарушает
условие «одинаковые границы на обе даты». Принят вариант Б.

Отдельно проверено взвешивание: на этих широтах пиксель CCI занимает 0,565 га,
а не 1 га; наивный подсчёт завысил бы площадь и запас в 1,77 раза.

## 3. Эксперимент 2: участок с изменением и контрольный участок (2019–2024)

| Участок | Запас 2019 → 2024, т C/га | E, т CO₂-экв. | Очагов | Доля вне очагов |
|---|---|---|---|---|
| RU_TVER_01 (контроль) | 85,13 → 86,14 | −6 485 (накопление) | 0 | 100 % |
| RU_VOLOGDA_02 | 75,71 → 71,57 | +24 604 | 26 | 12 % |
| RU_MORDOVIA_03 | 36,42 → 17,63 | +126 073 | 9 | 13,6 % |
| RU_MORDOVIA_04 | 13,18 → 2,44 | +72 154 | 7 | 1,5 % |

Положительное E — потеря углерода из учитываемого пула. На контрольном участке
очагов нет, изменение слабое и выделяется только как диффузный прирост. В
Мордовии-03 один очаг P001 (1040,6 га) даёт 84 % результата; в Мордовии-04
очаг P001 (1303,7 га) даёт 97,8 %.

## 4. Эксперимент 3: расхождения источников на очаге Мордовии-03 (P001)

* CCI показывает падение биомассы на −59,1 т/га на 1040,6 га.
* GFC отмечает потерю покрова с кодами периода лишь на 285,3 га, то есть
  примерно в 3,6 раза меньше.
* Продукт гарей MODIS в контуре очага горения не отметил, хотя по
  `events.csv` в августе 2021 года горение отмечено у 60 из 88 центров
  пикселей внутри всего участка.
* Окна дат по источникам не пересекаются: сервис показывает окна каждого
  источника отдельно и не выдаёт пересечение, которого нет.

Вывод: нарушение подтверждено (CCI + снимки), но причина **не установлена**;
это единственно допустимый статус. Пожар — гипотеза, которую данные на этом
очаге не подтверждают. На Вологде источники согласуются лучше: очаги
P001–P002 (69 га и 22 га) подтверждены GFC (63,5 и 30,3 га), статус A2.
Совпадение спутниковых продуктов не является независимой наземной проверкой.

## 5. Эксперимент 4: чувствительность к базовой линии

R = E_base − E_proj − LK, при LK = 0. Единиц нет ни в одном из сценариев.

| Участок | R, случай (т CO₂-экв.) | R, «нулевая динамика» | R, траектория контрольного участка |
|---|---|---|---|
| RU_TVER_01 | −4 547 | +6 485 | −4 547 |
| RU_VOLOGDA_02 | −21 521 | −24 604 | −34 799 |
| RU_MORDOVIA_03 | −42 853 | −126 073 | −137 603 |
| RU_MORDOVIA_04 | −73 649 | −72 154 | −83 704 |

Интерпретация зависит от базовой линии. На Твери при «нулевой динамике» R > 0,
но диапазон неопределённости (H/R ≈ 24,7) не позволяет получить единицы:
Q = 0. Общая базовая линия кейса на Мордовии-03 сама предполагает потерю
+83 220 т CO₂-экв., поэтому результат хуже базовой линии на 42 853 т, а не на
все 126 073 т. Основной расчёт единиц всегда идёт по таблице кейса;
остальные сценарии исследовательские.

## 6. Эксперимент 5: модель ошибок и ширина диапазона

Полуширина диапазона H по четырём моделям пространственной зависимости ошибок
CCI, т CO₂-экв.:

| Участок | Независимые | Эксп., L = 1 км (основная) | Полная корреляция |
|---|---|---|---|
| RU_TVER_01 | 6 690 | 160 236 | 376 616 |
| RU_VOLOGDA_02 | 3 319 | 78 088 | 178 245 |
| RU_MORDOVIA_03 | 2 289 | 42 639 | 100 870 |
| RU_MORDOVIA_04 | 796 | 11 720 | 26 843 |

Основная модель шире «независимой» в 15–24 раза, полная корреляция — в 34–56 раз.
Поэтому на контрольном участке накопление −6 485 т при независимых ошибках
отличимо от нуля (диапазон −13 175…+205), а при основной модели диапазон
−166 721…+153 751 включает ноль. Диапазон **сценарный**, а не эмпирически
калиброванный: независимых наземных измерений в наборе нет, длина
корреляции L = 1 км — допущение. Версия «согласовано с продуктом разности
ESA» даёт почти тот же результат, что и основная (ρ ≈ 0).

## 7. Ограничения

* Спутниковые продукты сравниваются между собой; это не наземная валидация.
* CCI — годовая модельная оценка с разрешением 100 м; мелкие изменения
  сопоставимы с её погрешностью.
* Учитывается только живая надземная биомасса. Потеря E не равна немедленному
  выбросу в атмосферу; корни, мёртвая древесина и почва не входят.
* Потенциальные единицы — расчёт по условиям кейса, а не сертифицированные
  единицы; базовая линия — сценарное допущение, а не доказательство
  дополнительности.
* Ни на одном из четырёх участков за 2019–2024 годы единицы не получены
  (Q = 0): по общей базовой линии кейса R < 0 на всех четырёх, то есть
  результат не лучше базовой линии.
* Получение Sentinel-2 по STAC реализовано в коде, но в этом отчёте все
  результаты получены по сохранённым файлам набора.
